# DX Paperbag · 穿孔挂绳真实遮挡版（v4）

本工程直接以你上传的 **DX-Paperbag-Three-Softbody** 原始站点为基础修改，保留原来的标题字体、薄荷绿 3D 材质、心形/星形装饰、DX 顶部位置、纸袋软体与页面其它交互；不是新建一个独立演示站点。

## 运行

需要 Node.js 20.19+ / 22.12+，在项目根目录执行：

```bash
npm install
npm run dev
```

访问 Vite 输出的地址（一般是 http://localhost:5173）。

完整检查：

```bash
npm test
npm run build
```

## v4 修复：字母遮住背面的绳子

用户反馈：在 `Xiao` 的 `o` 内孔附近，后侧的绳子看起来直接穿透实体笔画，缺少真实 3D 前后遮挡。

本版同时改了渲染和路径：

1. **不再使用写死的绳子 Z 值**：每一帧，在字母摆动、缩放、旋转后读取其实际 3D 变换，通过字母模型包围盒的 8 个顶点计算最近和最远深度。外侧绳段在字母正面；U 形后侧绳段放到字母最远背面（另外预留绳子半径）。
2. **真实深度遮挡**：每个实体字添加一个与真实字母几何完全一致的、不写颜色而只写深度的 Mesh。这样 `o`、`g` 内孔是真正的洞，绳子穿过洞可见，绳子在实体笔画背后则被遮住，**不是通过画一层二维遮罩作弊**。
3. **透明排序修正**：原字母保留原来透明渐入、薄荷色材质，深度网格先绘制、可见字母随后绘制、绳子最后绘制并进行深度测试，避免透明物件排序让绳子意外浮到表面。
4. **保持 v3 行为**：一个顶部固定环、三条独立绳、原字体与心/星装饰、物理摆动、偏心重力、拖动、与页面滚动解耦，全部保留。

编辑位置：`title-hover.js` 的 `glyphDepthRange()`、`occlusionMaterial`、`wire.mesh.renderOrder`，以及 `threaded-rope.js` 的 `zFront/zBack` 控制点。

注意：本项目仍是二维刚体力学与三维绳路视觉模拟；没有升级成真实的三维绳子-实体字连续碰撞系统。深度遮挡是由实际的 3D 几何深度测试实现的。

## 这次针对反馈的变化

### 1. 红线风格：绳子从上沿弯进字母内孔

三根吊绳从**同一个** DX 附近的金属环出发，分别走入 `Ding` 的 `g`、`Xiao` 的 `o`、`dong` 的 `o` 内孔。每条绳子采用**顶部一股 → 字母上沿肩部 → 内孔弯曲 → 孔内下缘 U 形兜住 → 另一侧穿出 → 顶部另一股**的穿线路径，而不是画一条直线横穿文字，也不是在字母外侧捆结。

`threaded-rope.js` 为该路由生成 3D 轨迹；真正的前后 Z 层加实际字形的深度缓冲形成穿孔遮挡；`title-hover.js` 中的 Verlet 粒子仅用于悬空段柔性，孔内段始终随字形刚体运动，避免绳子漂离孔洞。

### 2. 从出现起保持受力，取消中途“卡一下”

原先问题：`dx:bag-scroll` 触发 `dropStartAt`；变形时间线达到结束阈值时调用 `body.reset()`，造成中间一帧的定位跳变。

现在：
- 文字揭幕后，从**第一帧**就启动每组独立刚体、偏心重力与弹性绳张力。
- 保留最初占据一整行的立体字开场效果；之后绳长及字的整体大小随**真实时间**逐渐变化，位移/旋转只来自连续物理模拟。
- **不再存在滚动阈值触发的释放、reset 或角度交接**。
- `Ding`/`Xiao`/`dong` 拥有独立重心、转动惯量、绳长与拖拽受力。

### 3. 滚动后启动挂件动画，之后连续运行

开场揭幕后立即显示完整的 3D 标题和穿孔吊线，但保持静止；首次实际页面滚动时才启动重力与挂件运动。启动后，绳索与文字在固定的、透明的 WebGL 画布上连续运行，顶部仍共用原来的 DX 金属环，不会随滚动进度重置或暂停。吊线的落位长度已缩短约一半。鼠标拖拽仍有效，不占用菜单链接的点击交互。

**设计取舍：** 当你滚动到网站下方，三组吊坠仍悬浮在视窗顶部区域，这是根据你“动画一直存在、不受滚动影响”的明确要求处理的；如未来想设置“滚动后收缩到右上角”，应将其作为另一个视觉布局需求，不要直接改动物理状态。

## 调整参数

在 `title-hover.js`，滚动从初始 3D 姿态启动重力，并在 1.45 秒内连续缩小文字、收短吊线至初始长度的一半；不叠加逐字入场动画。
- `gust`：持续轻微吹拂的环境风力，可修改或设为 0。
- `threaded-rope.js`：绳子越过外沿以及进入内孔的路径控制点。

`?physicsDebug=1`：显示三组文字质心和各自的等效穿孔受力点。

## 真实性和限制

这是**屏幕平面的带质量刚体 + 弹性只拉不推绳索张力 + 绳段 Verlet + 三维穿孔路径**的工程近似，而不是完整绳/字母网格的连续接触求解。孔内的 U 形轨迹由字体内孔尺寸生成，受力点放在孔内下缘；没有连续计算摩擦、内孔壁接触漂移、绳体自碰撞、绳索三维扭结。

同一个顶部固定点、三条不同长度的绳，在没有持续横向外力时会趋于竖直；当前只施加轻微空气吹拂以产生自然幅度的长期摆动，不强行写死每个词的旋转角度。
